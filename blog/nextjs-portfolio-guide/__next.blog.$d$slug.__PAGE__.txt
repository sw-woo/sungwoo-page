6:T7c3,<h1>Next.js로 포트폴리오 웹사이트 만들기</h1>
<p>개발자에게 포트폴리오는 자신을 표현하는 중요한 수단입니다. 이 글에서는 Next.js를 사용하여 현대적인 포트폴리오 웹사이트를 만드는 방법을 알아봅니다.</p>
<h2>왜 Next.js인가?</h2>
<p>Next.js는 다음과 같은 이점을 제공합니다:</p>
<ol>
<li><strong>서버 사이드 렌더링(SSR)</strong>: 더 나은 SEO</li>
<li><strong>정적 사이트 생성(SSG)</strong>: 빠른 로딩 속도</li>
<li><strong>파일 기반 라우팅</strong>: 직관적인 구조</li>
<li><strong>이미지 최적화</strong>: 자동 이미지 최적화</li>
</ol>
<h2>프로젝트 설정</h2>
<pre><code class="language-bash">npx create-next-app@latest my-portfolio
cd my-portfolio
npm install
</code></pre>
