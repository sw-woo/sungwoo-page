19:T1a5d,<h1>RAG 시스템 성능 문제 해결기</h1>
<h2>문제 상황</h2>
<p>pdf-rag-streamlit 프로젝트를 진행하면서 심각한 성능 문제에 직면했습니다.</p>
<h3>발생한 문제들</h3>
<ol>
<li><strong>느린 검색 속도</strong>: 100페이지 이상의 PDF에서 쿼리 응답 시간이 10초 이상</li>
<li><strong>부정확한 답변</strong>: 관련 없는 문서 청크가 검색되어 LLM이 잘못된 답변 생성</li>
<li><strong>메모리 오버플로우</strong>: 대용량 문서 처리 시 메모리 부족 에러 발생</li>
</ol>
<h2>원인 분석</h2>
<h3>1. 비효율적인 문서 청킹</h3>
<pre><code class="language-python"># 문제가 있던 코드
text_splitter = CharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=0  # ❌ 오버랩 없음
)
</code></pre>
<p><strong>문제점</strong>:</p>
<ul>
<li>오버랩이 없어 문맥이 단절됨</li>
<li>고정 크기로 인해 문장이 중간에 잘림</li>
</ul>
<h3>2. 잘못된 임베딩 전략</h3>
<pre><code class="language-python"># 비효율적인 방식
for chunk in chunks:
    embedding = get_embedding(chunk)  # ❌ 하나씩 처리
    vector_store.add(embedding)
</code></pre>
<p><strong>문제점</strong>:</p>
<ul>
<li>순차 처리로 인한 속도 저하</li>
<li>API 호출 오버헤드</li>
</ul>
<h2>해결 방법</h2>
<h3>1. 스마트 청킹 전략</h3>
<pre><code class="language-python"># 개선된 코드
from langchain.text_splitter import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,       # 더 작은 청크
    chunk_overlap=100,    # ✅ 20% 오버랩
    separators=["\n\n", "\n", ". ", " ", ""],  # 우선순위 기반 분할
)
</code></pre>
<p><strong>개선 효과</strong>:</p>
<ul>
<li>문맥 보존: 오버랩으로 경계 정보 유지</li>
<li>의미 단위 분할: 문장/단락 기준으로 자연스럽게 분리</li>
</ul>
<h3>2. 배치 임베딩 처리</h3>
<pre><code class="language-python"># 최적화된 방식
def batch_embed(chunks, batch_size=32):
    embeddings = []
    for i in range(0, len(chunks), batch_size):
        batch = chunks[i:i + batch_size]
        batch_embeddings = embedding_model.embed_documents(batch)  # ✅ 배치 처리
        embeddings.extend(batch_embeddings)
    return embeddings
</code></pre>
<p><strong>개선 효과</strong>:</p>
<ul>
<li>처리 속도 5배 향상</li>
<li>API 호출 횟수 90% 감소</li>
</ul>

import tracemalloc

# 성능 측정 래퍼
def measure_performance(func):
    def wrapper(*args, **kwargs):
        tracemalloc.start()
        start_time = time.time()

        result = func(*args, **kwargs)

        elapsed_time = time.time() - start_time
        current, peak = tracemalloc.get_traced_memory()
        tracemalloc.stop()

        print(f"Time: {elapsed_time:.2f}s")
        print(f"Memory: {peak / 1024 / 1024:.2f}MB")

        return result
    return wrapper
</code></pre>
